Paso 1 • Resumen del Proyecto

Construye "GitHub Comic Heroes" con Google Antigravity 2.0

En esta guía práctica recorreremos los Pasos 2 al 9 del Codelab oficial Getting Started with Google Antigravity construyendo una aplicación completa: un generador de cartas coleccionables estilo cómic a partir de cualquier usuario de GitHub.

AGENTIC VIGILANTE (#154)

Cómo funciona: Ingresas cualquier usuario de GitHub. La aplicación descarga su foto de perfil real y sus repositorios principales, transforma su foto en una ilustración de superhéroe de cómic usando gemini-nano-banana-2.1 en Vertex AI y genera sus superpoderes y su frase de batalla.

Node.js 22 • @google/genai • gemini-nano-banana-2.1 • Cloud Run

Paso 7 • Sección 7 del Codelab

Artifacts: Plan de Implementación y Walkthrough

Cuando ejecutas /plan, Antigravity genera un Implementation Plan en el Auxiliary Pane (esquina superior derecha) para que puedas revisarlo y aprobarlo con Proceed antes de modificar archivos, y al finalizar genera un Walkthrough con el resumen y los diffs.

Opción A: Construir toda la aplicación desde cero con /plan

Prompt 7A — Construir App Completa
/plan Diseña y construye la aplicación "GitHub Comic Heroes" en Node.js (usando el skill global `github-comic-heroes` si está disponible): 1. `src/github.js`: consulta la API pública de GitHub (`https://api.github.com/users/` y `/repos`), obtiene los lenguajes principales, top 3 repositorios y descarga la foto de perfil (`avatar_url`) en base64. 2. `src/comic-ai.js`: usa `@google/genai` con Vertex AI (`vertexai: true`, `location: "global"`) para transformar en paralelo la foto de perfil real en una ilustración de superhéroe de cómic americano con el modelo `gemini-nano-banana-2.1` (`responseModalities: ["IMAGE"]`, `aspectRatio: "3:4"`) y generar con `gemini-3.8-flash` el alias de héroe, 2 superpoderes con puntaje PWR basados en sus repositorios y un grito de batalla. 3. `src/cli.js`, `src/server.js` y `public/index.html`: interfaz web estilo cómic en el puerto 8080 con trama halftone, insignia circular de la foto original junto al retrato ilustrado y galería Hall of Heroes. 4. Genera también el archivo `demo_bad_code.py` y el skill `.agents/skills/code-review/SKILL.md` para la etapa de auditoría. No uses diagramas Mermaid en el plan.

Opción B: Extender la aplicación en vivo con /plan
